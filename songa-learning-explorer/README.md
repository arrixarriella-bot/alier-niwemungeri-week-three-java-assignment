# Songa Learning Resource Explorer

This project is a simple learning resource tracker built with HTML, CSS, and JavaScript. It helps users explore learning materials, search by keyword, filter by category, and mark resources as completed.

## Features

- Search resources by title or description
- Filter resources by category
- View a dynamic list of learning resources
- Toggle each resource between completed and incomplete status
- See live progress counts for total resources and completed items
- Display a helpful message when no resources match the current search/filter combo

## Project Files

- `index.html` — page structure and controls
- `style.css` — page styling and responsive layout
- `script.js` — logic for data, filtering, search, and updates

## How to Run

Open `index.html` in a browser to use the app.

## Learning Focus

This project practises:

- JavaScript variables and data types
- Arrays and objects
- Loops and functions
- DOM selection and updates
- Event listeners and event delegation
- Search and filtering logic
- Progress tracking in the user interface
